Los métodos de un paso avanzan desde (ti, Ti) usando una pendiente promedio. Euler usa solo la pendiente inicial (orden 1); Heun y Ralston promedian dos pendientes (orden 2); RK4 combina cuatro (orden 4). RK4 se usa como referencia numérica de mayor orden, no como solución exacta.

$$\frac{dT}{dt} = f(t, T) = \alpha\,(P(t) - P_{idle}) - \beta\,(T - T_{entrada}(t))$$
$$\text{Euler: } T_{i+1} = T_i + h\,k_1,\quad k_1 = f(t_i, T_i)$$ $$\text{Heun: } k_2 = f(t_i + h,\, T_i + h k_1),\quad T_{i+1} = T_i + \tfrac{h}{2}(k_1 + k_2)$$ $$\text{Ralston: } k_2 = f(t_i + \tfrac{3}{4}h,\, T_i + \tfrac{3}{4}h k_1),\quad T_{i+1} = T_i + \tfrac{h}{3}(k_1 + 2k_2)$$ $$\text{RK4: } k_2 = f(t_i + \tfrac{h}{2}, T_i + \tfrac{h}{2}k_1),\ k_3 = f(t_i + \tfrac{h}{2}, T_i + \tfrac{h}{2}k_2),\ k_4 = f(t_i + h, T_i + h k_3),\ T_{i+1} = T_i + \tfrac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)$$

¿Por qué Heun y Ralston dan lo mismo? Todos los métodos RK de dos etapas y orden 2 solo difieren en términos con ftt, ftT y fTT. En la prueba automática con una EDO no lineal sí difieren.
